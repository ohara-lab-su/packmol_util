# CHANGELOG

## 2026.10.07, v0.2.4

- Minor adjustments for public release

## 2026.07.06, v0.2.3

- Added configuration support
  - Introduced `config.py` to centrally manage settings across the library
  - Enabled sample scripts to use `config.yml`
  - Allowed settings to be specified directly in scripts when `config.yml` is not used

- Added density conversion examples
  - Added `make_number_density.py`
    - Demonstrates how to calculate number density from mass density
    - Uses `Packmol.number_density_from_mass_density()`
  - Added `make_mass_density.py`
    - Demonstrates how to calculate mass density from number density
    - Uses `Packmol.mass_density_from_number_density()`

- Refactored sample code
  - Updated density conversion examples to use existing library methods
  - Removed duplicate implementations of density conversion formulas
  - Simplified the sample scripts so that switching between `config.yml` and directly specified settings only requires commenting or uncommenting code

## 2026.06.29, v0.2.2

- Extended FNC output functionality
  - Added the `fnc_output_constraint_types` option to `add_template()` in `builder.py`
  - Enabled selection of constraint types written to the RMC `.fnc` file without changing the template geometry used by Packmol
  - Previously, all defined FNC constraints were output; now only the required constraint types can be selected
  - Preserved backward compatibility by keeping the previous behavior as the default (`None`)

- Updated the Li3PO4 example
  - Added a usage example of `fnc_output_constraint_types` to `make_Li3PO4.py`
  - Added an example configuration that includes P–O constraints in the FNC output while excluding O–O constraints
  - Added comments explaining how to change constraints on the RMC side while retaining the same initial structure generated by Packmol

## 2026.06.07, v0.2.1

- Updated comments and documentation

## 2026.06.07, v0.2.0

- Refactored the builder and corresponding `make_*` scripts
  - Standardized the argument name of `add_template()` in `builder.py` back to `number`, establishing a general interface for specifying the number of copies
  - Updated `make_FeSiB.py` and `make_Li3PO4.py` to clearly distinguish and organize data structures for single-atom systems and systems containing molecular units
  - Exposed `builder.multiplier` (the overall scaling factor) as a public property, enabling automatic calculation and centralized management of placement counts for each structural unit
- Improved the README

## 2026.06.07, v0.1.0

- Introduced the Builder class to reduce complexity in user scripts

## 2026-06.07, v0.0.1

- Initial practical-use phase
  - Improved how distances and other constraints are specified, particularly for PO4 units

## 2026-06.06, v0.0.0

- Testing phase
